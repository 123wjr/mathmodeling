# Data Strategy

## 1. 项目数据策略

竞赛题目不提供原始实测数据，因此本项目不直接假定存在完整的真实训练数据，而采用：

> **公开数据/文献确定退化规律与参数边界 + 参数化仿真生成完整时序数据**

的策略。

公开来源主要用于回答：

1. 电池退化趋势是否合理；
2. 参数范围是否具有实验依据；
3. 不同温度、倍率、DOD等因素是否具有合理的影响方向；
4. SOH、RUL及梯次利用评价指标如何定义。

最终用于模型训练和多工况实验的数据由G1阶段的固定随机种子模拟器生成。

------

# 2. 候选公开数据源

## 2.1 CALCE Battery Data

来源类型：

公开电池实验数据集。

CALCE数据包含锂离子电池循环、容量、阻抗等实验信息，并包含不同电芯及不同实验条件。

其中部分数据可以提供：

- 电池额定容量；
- 循环过程；
- 容量变化；
- 阻抗变化；
- 温度条件；
- 不同电芯之间的差异。

因此CALCE数据可以同时服务于：

- 问题1：性能退化特征分析；
- 问题2：SOH/RUL建模；
- 问题4：多工况和电芯差异分析。

------

## 2.2 NASA Battery Dataset

来源类型：

公开电池实验数据集。

NASA公开数据包含电池循环过程中的电流、电压、温度、容量及退化相关信息，可用于构建容量随循环变化的退化轨迹。

因此可用于：

- 问题1：容量退化规律；
- 问题2：SOH/RUL预测；
- 问题4：不同电芯退化轨迹和工况扰动分析。

但NASA数据中不同数据子集的电池类型和实验协议存在差异，因此在正式使用前必须逐个核验化学体系、额定容量、温度、倍率、DOD及充电协议，不能将所有NASA数据视为同一化学体系。

------

# 3. 推荐主化学体系

经 G0 总负责人验收，本项目冻结：

> **NMC（LiNiMnCo/Graphite）锂离子电池**

作为主要模拟对象。

选择NMC的主要理由：

1. 与动力锂电池应用背景具有较好的工程对应性；
2. 公开退化研究和实验数据较丰富；
3. 容量衰减、内阻变化以及温度/倍率影响均有公开研究基础；
4. 适合作为问题1中的退化规律分析以及问题2中的SOH/RUL预测对象；
5. 后续可以进一步扩展至梯次利用场景。

主校准对象为 CALCE 中已标识为 NMC 的 INR18650-20R 电芯记录；NASA 数据仅作为候选外部对照，未逐条核验前不得用于寿命参数合并拟合。

------

# 4. 数据使用原则

公开数据不直接作为“真实万能数据集”使用，而按照以下原则处理：

### 原则1：来源优先于假设

如果公开数据能够直接给出参数，则优先采用公开数据。

### 原则2：实验范围优先于外推范围

如果某来源只覆盖25℃，不能据此声称25--50℃均有实验依据。

### 原则3：事实和假设分离

实测或来源明确给出的参数标记为 `OBSERVED`；文献定义但由本研究固定的阈值标记为 `LITERATURE_FIXED`。

为了生成仿真数据而自行设定的参数标记为 `ASSUMED`，必须同时记录数值范围、单位和敏感性分析计划。

### 原则4：不同化学体系不混合校准

不同化学体系的数据不能直接混合用于估计同一个退化参数。

------

# 5. 数据限制

## 5.1 化学体系限制

公开数据集中的电芯型号和化学体系并不完全一致，因此正式建模时不能简单合并不同体系的数据。

------

## 5.2 工况覆盖限制

不同来源对温度、倍率、DOD和充电协议的覆盖范围不同。

因此：

> 数据没有覆盖的工况不能被描述为“有实测证据”，只能作为仿真场景。

------

## 5.3 测量定义限制

不同数据源可能采用不同的容量、内阻和寿命定义。

在合并数据前需要统一：

- 容量测量方法；
- 内阻/阻抗测量方法；
- SOH定义；
- EOL定义；
- RUL定义。

------

## 5.4 模拟数据限制

G1生成的数据是参数化模拟数据，不是真实实验数据。

因此模拟结果只能用于：

- 算法开发；
- 模型比较；
- 敏感性分析；
- 鲁棒性分析；
- 方法验证。

不能据此声称模型已经在真实车辆电池上得到验证。

------

# 6. G0到G1的衔接

G0阶段完成：

公开来源核验 → 参数边界确定 → 主化学体系确定 → 仿真协议确定。

在总负责人批准主化学体系和参数边界后，G1阶段生成：

- 多电芯容量轨迹；
- 多电芯内阻轨迹；
- 不同温度工况；
- 不同倍率工况；
- 不同DOD工况；
- 电芯个体差异；
- 测量噪声。

生成的数据进一步服务于四个研究问题：

问题1 → 退化规律分析

问题2 → SOH/RUL预测

问题3 → 梯次筛选与编组

问题4 → 多工况和鲁棒性分析
