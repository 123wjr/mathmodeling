# Simulation Protocol

## 1. Simulation Objective

本仿真用于为竞赛四个研究问题提供统一、可复现的电池退化时序数据。

主要生成：

- 电池容量轨迹；
- 内阻轨迹；
- SOH；
- 循环次数/EFC；
- 温度、倍率、DOD等运行工况；
- 电芯个体差异；
- 测量噪声；
- 膝点（knee point）。

模拟数据用于后续问题1至问题4的模型开发、比较、敏感性分析和鲁棒性验证，不作为真实实验数据的替代。

------

## 2. Simulation Unit

基本模拟单位为“单颗电芯”。

每颗电芯具有独立的：

- 初始容量；
- 初始内阻；
- 退化速率；
- 随机效应；
- 测量噪声。

正式数据规模由配置文件控制。

G1冒烟测试至少生成3颗电芯。

------

## 3. Cycle and EFC

循环次数使用 `cycle` 表示。

同时计算等效完整循环数（EFC）：

[
EFC=\sum_i \frac{DOD_i}{100}
]

例如：

- 一次100%DOD循环 = 1 EFC；
- 一次50%DOD循环 = 0.5 EFC；
- 两次50%DOD循环 = 1 EFC。

后续退化模型优先使用EFC作为累计老化量，同时保留原始cycle字段。

------

## 4. Operating Conditions

仿真考虑以下工况变量：

### Temperature

G0冻结可生成范围为 25--50 degC，主场景使用 25、35、45 degC。

- 25℃
- 35℃
- 45℃

超过 50 degC 的结果只能作为未校准压力测试，不得写成公开数据支持的工况。

------

### C-rate

考虑不同充放电倍率。

G0冻结可生成范围为 0.5--2C，主场景使用：

- 0.5C
- 1C
- 2C

超过 2C 的结果只能作为未校准压力测试。

------

### DOD

考虑：

- 50%
- 80%
- 100%

DOD用于计算每个循环对应的EFC，并作为退化速率修正因素。

------

## 5. Charging Protocol

默认采用CC-CV充电协议。

协议包含：

1. 恒流（CC）阶段；
2. 达到上限电压后的恒压（CV）阶段；
3. 达到截止电流后结束充电。

如果公开数据源采用不同充电协议，则必须在数据源记录中单独标记，不能直接视为CC-CV数据。

------

## 6. Capacity Degradation

定义：

- `Q0`：初始容量；
- `Q(n)`：第n个EFC对应的可用容量。

容量随老化总体下降。

G1 使用可解释的分段平方根退化函数。令 `e` 为累计 EFC，
`u_T=exp(k_T*(T-25))`，`u_C=1+k_C*(C_rate-0.5)`，
`u_D=1+k_D*(DOD/100-0.5)`，则电芯 `i` 的真实容量为：

令 `L(e)=sqrt(min(e,n_k)) + knee_gain*max(0,sqrt(e)-sqrt(n_k))`，则
`SOH_i(e) = 1 - alpha_i * u_T * u_C * u_D * L(e)`，其中
`alpha_i = alpha * (1 + eta_i)`，`knee_gain = 2.0`。该写法在膝点处连续，且只在
膝点后提高退化斜率。`alpha`、`k_T`、`k_C`、`k_D` 和 `n_k` 的 G0 边界见
`evidence/parameter_ledger.txt`，均为 `ASSUMED`。

模型需要满足：

1. 正常工况下容量总体下降；
2. 温度升高时退化速度可增加；
3. 倍率增加时退化速度可增加；
4. DOD增加时退化负担可增加；
5. 不同电芯具有不同退化速度。

该形式只表达容量退化趋势，不宣称完整电化学机理，也不把仿真轨迹当作实测轨迹。

------

## 7. Internal Resistance

定义：

- `R0`：初始内阻；
- `R(n)`：第n个EFC对应的内阻。

G1 使用与容量相同的工况修正和分段结构：

`R_i(e) = R0_i * [1 + beta_i * u_T * u_C * u_D * L(e)]`，其中
`beta_i = beta * (1 + eta_Ri)`，`L(e)` 与容量公式相同。
`R0_i` 和个体随机效应的取值必须来自冻结的参数边界；负值或超出输入范围的记录直接拒绝。

模型需要满足：

1. 内阻总体上升；
2. 高温、高倍率和高DOD工况可以表现出更快的增长；
3. 不同电芯存在初始内阻和增长速率差异。

------

## 8. Random Effects

为了模拟真实电芯之间的差异，为每颗电芯设置随机效应。

随机效应作用于：

- 初始容量；
- 初始内阻；
- 容量衰减速度；
- 内阻增长速度。

例如：


$\theta_i=\theta_0(1+\epsilon_i)$


其中 `epsilon_i` 和 `eta_i` 独立服从截断正态分布 `Normal(0,sigma_cell)`，截断在
`[-2*sigma_cell, 2*sigma_cell]`；截断后重新缩放初始容量和内阻，确保为正且仍在台账范围。
`sigma_cell` 是 `ASSUMED`，由固定随机种子控制。

随机效应不能导致明显违反基本物理趋势的轨迹。

------

## 9. Knee Point

定义膝点为容量退化速度由缓慢阶段转入明显加速阶段的位置。

模拟器需要能够产生：

### Knee point之前

较低的容量衰减速率。

### Knee point之后

较高的容量衰减速率。

可使用分段退化函数表示：

$Q(n)=\begin{cases}Q_{\mathrm{pre}}(n), & n<n_k\Q_{\mathrm{post}}(n), & n\ge n_k\end{cases}$

其中：

- `n_k`：膝点；
- `Q_pre`：膝点前退化函数；
- `Q_post`：膝点后退化函数。

膝点位置可以在电芯之间存在随机差异。

------

## 10. Measurement Noise

容量和内阻均加入测量噪声。

容量：

$Q_{\mathrm{obs}}=Q_{\mathrm{true}}+\epsilon_Q$

内阻：

$R_{\mathrm{obs}}=R_{\mathrm{true}}+\epsilon_R$

`epsilon_Q ~ Normal(0, sigma_Q*Q_nom)`，`epsilon_R ~ Normal(0, sigma_R*R_true)`；
`sigma_Q`、`sigma_R` 是 `ASSUMED`，数值边界见参数台账。观测值在写出前截断到物理可行域
（容量 > 0、内阻 > 0），但不得用截断后的观测值反向拟合生成参数。

噪声只能模拟测量不确定性，不应改变总体退化方向。

------

## 11. Data Validation Rules

生成数据后必须满足：

### Capacity

- 总体下降；
- 不允许出现持续异常增长；
- SOH不能超过合理上界。

### Resistance

- 总体上升；
- 不允许出现长期异常下降。

### Reproducibility

相同随机种子：

> 输入配置相同 → 输出CSV完全一致。

不同随机种子：

> 输出应存在合理的电芯差异。

### Input Validation

以下输入必须拒绝：

- 非法温度；
- DOD < 0%；
- DOD > 100%；
- 非正倍率；
- 不支持的充电协议。

------

## 12. Scenario Design for Problem 4

问题4使用以下场景进行鲁棒性分析：

### Scenario A：高温

提高环境温度，观察：

- 容量衰减速度；
- 内阻增长速度；
- RUL变化。

### Scenario B：大倍率

提高C-rate，观察：

- 退化速度；
- SOH下降；
- 寿命变化。

### Scenario C：高DOD

提高DOD，观察：

- EFC变化；
- 容量衰减；
- RUL变化。

### Scenario D：电芯差异

增加电芯间随机效应，观察：

- SOH分布；
- RUL分布；
- 梯次利用分组稳定性。

------

## 13. Reproducibility

所有随机过程必须由固定随机种子控制。

G1至少提供一个固定种子，例如：

`seed = 42`

并确保：

相同配置 + 相同seed

得到完全相同的数据。

------

## 14. G0 / G1 Boundary

G0阶段确定：

- 主化学体系；
- 参数来源；
- 参数候选范围；
- 仿真变量；
- 模型结构；
- 合理性约束。

G0不要求生成最终数据。

G0通过后，G1 只能在上述边界内选择一组参数并记录配置、随机种子和哈希；不得改变变量定义、
公式形式或数据隔离规则。参数选择是仿真设定，不得在论文中表述为 CALCE 的直接实测估计。

------

## 15. Known Limitations

本仿真不是完整电化学机理模型。

不声称：

- 完整描述SEI增长；
- 完整描述锂析出；
- 完整描述热失控；
- 完全复现真实电芯；
- 通过模拟结果证明真实车辆电池上的模型有效。

模拟数据的用途限定为竞赛中的算法开发、模型比较、多工况实验和鲁棒性分析。
