# V2 增强论证包：机制一致性与反捷径审计

状态：`READY_FOR_REVIEW`。这是 V1 合成仿真结果的独立论证层，不替换 V1，不等同真实数据验证，也不扩建 Q3/Q4。

## 1. 运行

```bash
python technical/mechanism_argument.py \
  --study-output study_output \
  --out study_output/v2_mechanism_argument.json
```

脚本只使用 Python 标准库，输入固定为 `study_output/q1_factor_effects.csv` 和 `study_output/q2_leave_condition_out.csv`。输出 JSON 是可回指的新增证据，不改写已有 CSV/JSON。

## 2. 它增加什么说服力

第一版已经报告了总体主效应和 5 折 `GroupKFold(cell_id)`，但“模型是否只是记住某些工况/生成器结构”仍需要更明确的论证。此包增加两个可审计检查：

1. **机制方向一致性**：对容量衰减和内阻增长，逐因素读取 3 个边际均值，检查温度、倍率、DOD 是否单调增加，并报告最小相邻差值。它支持“在冻结支持域内与预设压力方向一致”的有限表述，不支持真实因果结论。
2. **工况留出反捷径检查**：汇总 27 个 `leave-condition-out` 折的平均/最坏 RMSE，以及每个模型相对 persistence 的胜出次数。它检验模型是否只依赖某一个工况，仍然属于同一合成数据族内的压力测试。

## 3. 当前结果（由脚本重算）

当前冻结产物应给出：

- 六组响应-因素边际均值均为单调增加（`increasing=true`）；容量衰减中 DOD 的主效应权重约 `0.7249`，温度约 `0.2378`，倍率约 `0.0373`。内阻增长的相应权重约 `0.7317/0.2346/0.0337`。
- 27 个工况留出折中，Ridge 与随机森林每一折都优于 persistence（胜出次数应为 `27/27`）；其平均和最坏 RMSE 由 JSON 精确给出。论文可将其写成“跨冻结工况留出仍保留增益”，不要写成外部泛化。

## 4. 论文可用表述

> 在冻结的 3×3×3 合成支持域内，容量衰减和内阻增长的边际均值随温度、倍率与 DOD 均单调增加；同时，逐工况留出实验中统计模型相对持久化基线保持误差下降。该结果只说明模型在设计域内遵循生成器设定的压力方向并利用了可观测状态信号，不能替代独立化学体系或测试协议的外部验证。
