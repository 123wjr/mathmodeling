## 三、队友 2：建模与代码负责人

### 人必须完成

1. 在 `model/g0-g1` 分支（或仓库现有等价分支）维护 G1 代码，并亲自复跑最终命令。
2. 检查 Agent 生成的公式、单位、边界和 CSV 字段，不接受“代码能跑”作为唯一验收依据。
3. 确认所有输出均来自固定配置和 seed；记录 Git commit、配置文件、运行命令和文件 SHA-256。
4. 不下载或上传私密材料；外部数据只使用 `source_ledger.txt` 已列入口，未核验字段写 `UNVERIFIED`。

### Agent 可执行

1. 编写最小生成器和 pytest 测试；先运行失败测试，再实现，再跑全套测试。
2. 输出至少 3 颗电芯、至少 1 个基准工况和 3 个压力工况的容量/内阻轨迹。
3. 生成容量轨迹、内阻轨迹、膝点前后斜率和工况分组对比图。
4. 输出数据字典，至少包含：`cell_id`、`cycle`、`efc`、`temperature`、`c_rate`、`dod`、`protocol`、`capacity_true`、`capacity_obs`、`soh`、`resistance_true`、`resistance_obs`、`seed`。

### 必测规则

- 相同配置 + 相同 seed 输出逐字节一致。
- 不同 seed 产生合理电芯差异。
- 容量总体下降，内阻总体上升；膝点后斜率高于膝点前。
- 拒绝温度超出 25--50 degC、DOD 不在 0--100%、非正倍率和不支持协议。
- 不随机拆分同一电芯循环记录；G1 不训练预测器。
