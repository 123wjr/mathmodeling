## 1. 唯一事实源与停止规则

发生冲突时按以下优先级裁决：

1. 总负责人签署的闸门结论与 `.codex/DECISIONS.md`。
2. 已验收且带版本/commit 的 A0-A5 证据包。
3. 可复跑的代码、测试、结果和哈希。
4. 任务书、在线文档草稿和 Agent 汇报。
5. 聊天中的数字、结论或“已经完成”。

**停止规则**：上一级事实与下一级文件冲突时，下一级不得继续生产结果。修复必须是新 commit，不重写历史，不静默删除队友材料。

```text

验证：命令、测试数、关键哈希或人工核验数
阻塞：问题 + 等谁决定；无则写 NONE
下一步：动作 + CST 截止
```

升级规则：

- `P0`：路线冲突、数据泄漏、引用/结果疑似虚构、核心结果不可复现。立即停工，10 分钟内报总负责人。
- `P1`：单个图表、脚本、章节或来源受阻。到最近检查点报告，优先降级范围。
- `P2`：措辞、样式、非核心图。记录后批量处理，不打断关键路径。
