## 一、统一规则

1. GitHub 是代码、参数、数据、图表和结果的唯一事实源；腾讯文档只承载论文正文。
2. Agent 输出都是候选。没有对应负责人验收，不得进入论文。
3. 不得编造论文、数据、参数、标准、DOI、页码、结果或运行记录。
4. 生成器、预测器、外部验证必须分开；同一电芯循环记录不得随机拆到训练集和测试集。
5. 当前只完成 G0/G1。不得提前堆叠 LSTM、Transformer、PINN、GAN、NSGA-II、PSO、AHP-TOPSIS 等模型。
6. 所有结论写成“在本研究假设与校准范围内”；80% SOH 不得直接称为安全失效阈值。
